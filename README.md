# Mutual Fund Analytics

## Project Overview
This project demonstrates data cleaning, exploratory data analysis (EDA), and business dashboard creation using Python and Power BI.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI
- Git & GitHub

## Project Files
- sales_data.csv
- cleaned_sales_data.csv
- data_cleaning.py
- eda.py
- Sales_Performance_Dashboard.pbix

## Data Cleaning
- Removed duplicates
- Checked missing values
- Validated data
- Performed basic statistics

## Exploratory Data Analysis
- Total Sales
- Average Sales
- Maximum Sales
- Minimum Sales
- Regional sales analysis
- County-wise sales analysis
- Salesperson performance

## Power BI Dashboard
The dashboard includes:
- Total Sales KPI
- Average Sales KPI
- Maximum Sales KPI
- Minimum Sales KPI
- Total Salespersons
- Sales by Region
- Sales by County
- Sales by Salesperson
- Region slicer for interactive filtering

## Key Business Insights
- North region generated the highest sales.
- Total sales across the dataset are 924.
- Average sales per transaction are 18.12.
- Sales range from 4 to 45.
- There are 51 unique salespersons.
